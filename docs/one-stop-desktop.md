# 一站式桌面操作

打开“恋聊教练”后，首页完成来信读取、填写自己的想法、生成和复制。

1. 确认“和谁聊”。切换对象后，双方资料、目标、历史和未保存草稿按对象隔离。
2. 程序尝试打开或恢复 Windows 微信。请登录并打开首页所选对象的私聊。浅色微信中，可见文字来信会作为候选自动填入左侧；识别失败会显示原因并暂停，人工处理后点击“重新连接”。
3. 核对来信，在“我的想法 / 希望怎么回”填写意思、语气要求或草稿。只有自己的想法也能生成主动表达，不需要伪造一条对方的来信。
4. 勾选使用聊天内容的同意框，点击“生成回复建议”。右侧显示可编辑回复、解释和下一步；暂停原因直接显示在首页。
5. 点击“复制回复”，到微信自行核对并发送。“先帮我分析”可用于分析当前情况。

人设、聊天目标、历史导入、重要记忆、模型与微信窗口设置均在“资料与设置”。详细分析页的“保存模式与问题”只保存；“保存并生成方案”才开始处理。

## 自动读取的范围

- 仅核对并读取首页已确认对象的当前微信窗口；不扫描通讯录、不代登录、不发送消息。
- 自动画面识别支持浅色主题中的可见文字气泡，结果需要本人核对；图片、语音、深色主题与不明确布局使用“手动选消息”。
- 默认每六秒检查一次，任务不重叠；识别异常后暂停，不无限重试。
- 正在编辑的来信不会被新候选覆盖，可点击“使用新来信”替换；切换对象后的迟到结果不会写入当前输入框。
- 自动填入新的候选会重置同意框。读取本身在本机执行，只有本人点击生成并同意后才提交所选上下文给模型。
- 画面读取不代表完整聊天历史，也不自动把识别候选记为已确认历史。
