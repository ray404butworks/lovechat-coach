# v0.3 军师架构

## 方法主体与版本

主体来自 [goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi/tree/6db7354a4002dc7c448a9c87ffdad8132570c9d3)，固定在 `6db7354a4002dc7c448a9c87ffdad8132570c9d3`。研究了其行为内核、架构、关键流程、知识治理、实战话术编排器、互惠决策与记忆程序。原文资料43份，MIT版权与许可完整保留。

采用的主链是：情绪承接 → 事实／推测／未知 → 利益判断 → 一个主动作 → 反馈分支 → 观察窗口与停止条件。原 OpenDate 的14个技能不再承担微信桌面的决策入口；其CLI和底层模块保留兼容，旧手动技能只作为表达偏好进入新上下文。

## 上游方法如何落地

| 上游设计 | LoveChat 实现 | 程序边界 |
| --- | --- | --- |
| 事实、推测、未知分离 | `coach/models.py` 的结构化合同 | 原文与来源ID逐条校验；事实不能来自旧假设。程序不能证明所有自然语言解释都成立，仍做模型复审。 |
| 一个主动作与后续分支 | `CoachAnswer` | 首选正文与内部建议分开；积极、含糊、拒绝、无回应均有分支。 |
| 分场景按需读取 | `coach/knowledge.py` | 11个场景；每次证据边界＋两份场景资料，不因库大而全量注入。 |
| 首选、理由、窗口与停止条件 | `coach/engine.py`、`coach/pipeline.py` | 结构、证据、模型复审任一失败不展示候选；有限重写。 |
| 精简分层记忆 | `coach/memory.py` | 来源限制、同意门禁、事务、上限、按对象召回、撤销及硬删除。 |
| 即时回复、复盘与演练 | 桌面“军师方案” | 四种模式；演练是模拟，不保存为真实事件。 |

## 保留与调整

保留历史导入、说话人映射、原始记录去重、对象隔离、人设、双方信息与目标、上下文预览、模型上传同意、密钥DPAPI、手动复制以及上一轮阶段／邀约修复。已有私有数据不迁移、不覆盖，也不会因为升级默认开启新的记忆功能。

上游首次问卷的MBTI与主观评分改为可选，避免阻塞眼前回复或把主观评分变成价值判断。上游记忆脚本的自动更新改为“模型提出候选 → 本人核对保存”，适合现有桌面的人工审阅方式。上游ChatLab和全局目录不是本项目的真实集成；本程序仍只使用已有TXT/JSON及经选择的私聊画面。

## 程序路径

```text
wechat_gui / lovechat-coach Skill
  → wechat_desktop：锁定对象、保存设置、预览与上下文预算
  → wechat_strategy：兼容旧设置、阶段与邀约辅助判断
  → coach.pipeline：边界与节奏 → 场景 → 原文证据 → 方案 → 独立复审
  → 正文 + 军师建议 + 待核对记忆候选
  → 人工复制 / 明确保存档案（两条独立路径）
```

模型只处理文本，不获得发送、文件、浏览器或本地档案操作权限。知识材料不能改变系统权限。新流程默认两次调用：方案和复审；失败时按配置有限重写。调用次数减少不代表生成质量已经完成真实模型验证。

## 数据和信任边界

- 原始聊天仍在原数据库；精简档案另用 `coach-memory.sqlite3`，不把模型输出写回原始聊天。
- `evidence_sources`保留当前消息、历史消息键、双方已确认信息、用户问题与旧记忆的来源类别。目标不作为对方承诺的事实来源。
- `CoachAnswer`限定事实原文、带依据和替代解释的推测、未知项、首选、理由、单主动作、正文、时机、代价、下一步、观察、停止条件和反馈分支。
- 原文校验是包含关系和来源存在性校验，不能替代语义验证；后续模型复审检查归属和建议，仍可能出错。
- 模型与导入材料不能新增稳定人格和关系共识。事件与假设候选需要本人确认后保存。
- 私人档案不进入公开知识库、日志、遥测或代码测试；测试使用合成对象和内容。

## 精简档案约束

本人30字段、对象15字段、关系10字段；每对象20事件和5假设；单条正文200字，总200条，撤销历史20次。相同对象／scope／field更新而非无界追加。假设另存置信程度。达到稳定字段或总量上限时拒绝事务；事件和假设按上限裁剪。忘记对象同时删除其撤销记录。

暂停与撤回同意后不自动召回档案；本人仍可查看、撤销或删除。删除精简档案不会删除独立保存的原始聊天、旧记忆或历史方案报告，界面会说明范围。

## 资料维护与验证

Agent资料与Python安装包各有副本，由 `scripts/sync_coach_references.py` 从固定版本同步；`--check`校验内容与哈希一致。`pyproject.toml`将参考资料、来源元数据和MIT许可包含进wheel，安装后不依赖仓库根目录。

附带知识含历史法律、医疗、统计和经验观点，不是实时权威。内核要求现行结论另行核验，不把任何资料标注的等级直接当作已核实。评测区分离线程序测试、合成模型传输、真实模型行为、真实微信接入，分别报告覆盖范围。
