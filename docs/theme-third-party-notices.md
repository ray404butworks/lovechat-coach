# Visual theme references

The native theme adapts ideas from Hallmark's Hum theme and the split-pane
interaction described by Open Claude UI. No proprietary fonts or binary
Anthropic assets are distributed. The native implementation is in
`src/opendate/wechat_theme.py`.
