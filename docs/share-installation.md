# 恋聊教练：安装与首次配置

恋聊教练（LoveChat Coach）是基于 [OpenDate Skill](https://github.com/sumitaich1998/OpenDate) 开发的微信约会聊天助手。保留其原始技能、阶段判断、口吻改写、质量复审与安全检查，并加入 Windows 图形界面、历史导入、双方记忆、人设、关系目标及首次配置引导。保留 OpenDate 的 MIT 许可证，不是微信、腾讯或模型服务的官方产品。

## 安装

1. 在 Windows 10/11 安装 Python 3.11 或更新版本，包含 Tcl/Tk，安装时勾选将 Python 添加到 PATH。
2. 下载完整项目 ZIP 并解压到有写入权限的文件夹。不要直接在压缩包中运行。
3. 双击根目录的 **恋聊教练.vbs**。图形进度窗口会建立项目专属环境并安装依赖；首次需要联网，不需要用户输入命令。
4. 安装完成后自动打开配置引导。再次双击会进入已有配置的主窗口。

这是带图形安装入口的源码项目，尚未提供独立 EXE。Codex 模式还需要用户自己安装 Codex 并使用 ChatGPT 登录；API 模式不需要安装 Codex。

## 七步提问引导

1. **选择 AI**：Codex 登录，或 DeepSeek、OpenAI、Claude API。
2. **模型与密钥**：API 模式填写服务当前可用的模型 ID，Codex 可留空。API Key 由用户在本机遮蔽输入框填写，完成时使用 Windows 当前用户 DPAPI 加密保存；Codex 模式检查已有登录，不收集密钥。此处的本地检查不等于实际网络和余额已验证。
3. **微信对象**：填写本人的微信显示昵称、目标对象完整唯一备注，建立单对象白名单。
4. **历史文件**：选择 TXT 或 JSON 并预览，或明确选择稍后导入。文件昵称不同于备注时，核对哪个是我、哪个是对方；多会话文件需选择具体会话 ID。
5. **人设与风格**：填写性格背景、聊天口吻、避免表达及本人语气示例。背景和示例可暂留空，风格可自定义。
6. **双方信息与目标**：分开填写本人和对方的已知信息，再写希望发展的关系、节奏与边界。不会把个人目标当成对方同意。
7. **核对并完成**：核对身份、条数、日期和配置，明确是否允许生成/整理时向所选服务上传相应上下文，确认后保存并导入。

可随时“保存进度，稍后继续”。草稿包含已填写的本人资料，属于本机私有数据；尚未提交的 API Key 不写草稿，恢复时需重新填写。已有用户不会强制重走引导；在“接入与说明”可重新打开。

## TXT 自动导入

支持以下结构，不同导出工具产生的其他 TXT 排列可能需要先整理：

```text
示例好友
2026年10月19日 21:22
今天去散步吗？

示例本人
2026年10月19日 21:23
好呀，晚饭后走走。
```

支持 UTF-8、带 BOM 的 UTF-16、GB18030；日期也支持横杠或斜杠，秒可省略，无时区的 TXT 按北京时间读取。保留正文换行、带“回复/引用”前缀的引用块、同一分钟顺序及源文件内原有重复消息；同一批内容重新导入不会再次增加。原始 TXT 绑定后，文件更新可继续同步。格式不明确、日期损坏或超过两位发送人时会提示检查，不部分导入。

## 使用与数据范围

主窗口支持指定微信窗口、粘贴来信、历史搜索、人设、双方信息、关系目标和约会策略。微信窗口读取取决于客户端版本与系统支持；可以先使用 TXT 导入与手动粘贴。图形 OCR 使用 Pillow、pywin32、psutil 和 Windows OCR。高级旧 UIA 接口另需用户安装 pyweixin-rpa 并配置其源码路径，不是基础 TXT 流程的必需条件。

历史数据库读取是单独的可选能力，需要兼容的读取器与用户授权，不保证所有微信版本都可解密。本项目未打包任何人的微信密钥、数据库、读取器授权缓存或模型登录令牌。

历史文字保存在本机数据库；回复使用当前来信、已确认记忆、近期消息和相关旧记录，不保证每次将整个历史提交给模型。分批整理历史会调用所选服务并消耗额度，记忆草稿由本人核对保存。照片、表情包、语音和附件正文未读取。

回复是草稿，由用户修改、复制后自行发送。生成与复制不等于已经发出，窗口没有发送按钮。

## 私有文件

`config.wechat.yaml`、`.env`、`data/`、`work/`、数据库、历史文件、截图、个人记忆及密钥保险箱不应上传 GitHub。保险箱与当前 Windows 用户绑定，换电脑需重新配置 API Key。忽略规则不能移除已经提交的秘密；共享前应使用项目打包器建立干净快照并扫描，不能直接压缩整个工作目录。

## Skill 安装

仓库内 `skills/lovechat-coach` 可安装到支持 `SKILL.md` 的 Agent。它描述同样的分步引导与运行边界；仅安装 Skill 不会自动安装 Python 图形程序和依赖，完整项目仍需下载。
