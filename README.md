# 恋聊教练 · LoveChat Coach

让回复更像你，也记得你们聊过什么。

**本项目基于 [OpenDate Skill](https://github.com/sumitaich1998/OpenDate) 开发**，保留原版约会技能、阶段判断、本人口吻改写、质量复审与安全检查，扩展为 Windows 个人微信的图形聊天助手。原版 MIT 许可证保留于 [LICENSE](LICENSE)，完整来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 安装与开始

Windows 10/11，Python 3.11+（包含 Tcl/Tk，并加入 PATH）。下载整个仓库 ZIP，解压后双击根目录 **恋聊教练.vbs**。

图形安装器会安装项目依赖，然后自动进入首次配置。**不需要手动输入命令**。当前提供源码与图形安装入口，尚未提供独立 EXE。

首次引导依次询问：

1. 选择 Codex 登录或 DeepSeek / OpenAI / Claude API。
2. 配置模型与本机 API Key；Codex 无需 Key。
3. 填写本人微信昵称、目标对象完整唯一备注。
4. 导入 TXT / JSON 历史，核对双方身份、条数和日期，或选择稍后导入。
5. 编写本人人设、聊天风格、禁用表达和语气示例。
6. 分开填写双方信息，设置希望达成的关系目标。
7. 核对内容及模型数据使用选项，确认保存后开始使用。

中途可保存进度。已有配置直接打开主窗口，可在“接入与说明”重新进入引导。详细步骤见 [安装与使用说明](docs/share-installation.md)。

## 能做什么

- 指定聊天对象与微信窗口；可读取当前私聊画面，也可手动粘贴来信。
- TXT 本地自动转换、JSON 导入、原始文件绑定同步、重复导入去重。
- 分清“我”和“对方”的历史发言、已知信息及记忆，按对象隔离保存。
- 自定义本人人设、聊天风格和关系目标，实际进入 AI 上下文。
- 使用 OpenDate 原版聊天技能完成开场、熟悉、调侃、暧昧、邀约、冷场修复等流程。
- 暖纸 / 夜间主题，回复分栏拖动，设置页滚动，长期记忆草稿供本人核对。
- 先预览 AI 使用的上下文，再生成、修改、复制；图形窗口没有发送按钮。

## 模型与隐私

Codex 模式复用本机 ChatGPT 登录，不读取或复制登录令牌。API 模式由用户在自己的本机填写密钥，Windows 当前用户 DPAPI 加密保存。仓库不包含任何人的 API Key、微信读取密钥、聊天记录、个人资料、数据库或账号缓存。

导入、检索和预览在本机完成。生成或分批整理记忆时，相应聊天、人设及目标会发送给用户选择的模型服务并使用其额度。完整文字档案留在本机，单次生成选择近期与相关旧记录，不能等同于每次提交全部聊天。

## 当前范围

支持 TXT 中的“昵称 → 日期时间 → 正文”结构；其他导出工具的排列不保证直接识别。保留多行正文、带前缀的引用和同一分钟顺序。图片、语音、表情包和附件正文未解读。

微信窗口 OCR 和可选数据库读取受客户端版本、系统能力与本机授权影响，不保证所有微信版本可用。基础流程可直接使用 TXT 导入与粘贴来信。高级 UIA 适配需另外安装 pyweixin-rpa，可选数据库读取器和用户授权缓存不随源码打包。

这是辅助表达与整理上下文的工具，不保证好感度、回复率或关系结果。关系目标代表本人的希望，应尊重对方的真实反馈和边界。

## Skill 与开发

`skills/lovechat-coach` 提供 Agent 可识别的 `SKILL.md` 和逐步配置流程。只安装 Skill 不会安装完整图形程序；请同时下载本项目。

核心实现保留 `opendate` Python 命名空间，方便复用原版功能。开发验证使用 `pytest` 与 `ruff`，Windows 图形与 DPAPI 测试在非 Windows / 无显示环境中会按能力跳过。源码分享包由 `scripts/package_share.py` 生成，只包含可分享文件，不携带本地 Git 历史。
