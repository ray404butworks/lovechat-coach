# 恋聊教练 · LoveChat Coach

把情绪接住，把事实看清，再决定这句话怎么说、下一步怎么走。

v0.3以 [goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi) 的方法架构为主体：**情绪 → 事实／推测／未知 → 利益判断 → 一个主动作 → 反馈分支 → 观察与停止**。保留 OpenDate 的桌面接入基础和 `opendate` 命名空间，完整来源与MIT许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 四种用法

| 模式 | 得到什么 |
| --- | --- |
| 帮我回复 | 一条符合本人口吻的正文，以及时机、代价和后续分支 |
| 分析局面 | 有原文依据的事实、暂定解释、关键未知、首选行动与停止条件 |
| 复盘我的表达 | 根据真实原话指出一个优点、一个改进点和替代表达 |
| 陪我演练 | 每轮一条模拟回复，练习接话与邀约；模拟不是对方真实想法 |

在“军师方案”页选择模式、场景，填写当前问题并保存；首页可粘贴对方来信，分别查看回复正文和军师建议。不再要求先从十个聊天技巧里挑一个。

普通开心、表情和调侃不自动等于暧昧。邀约分别判断提出、接受、拒绝、暂缓、改期待确认、取消、过期和完成；重复生成不会刷新真实消息日期，过期也不等于已经见面。

## 安装与开始

Windows 10/11，Python 3.11+（含Tcl/Tk并加入PATH）。下载整个仓库ZIP，解压后双击 **恋聊教练.vbs**。目前提供源码与图形安装入口，尚无独立EXE。

首次引导逐步配置：Codex/ChatGPT登录或DeepSeek、OpenAI、Claude API；模型和本机密钥；本人昵称与唯一对象备注；TXT/JSON聊天导入；人设、风格和语气示例；双方信息与目标；上传同意。中途可保存进度，已有设置保留。见 [安装与使用说明](docs/share-installation.md)。

只安装 `skills/lovechat-coach` 也可在Agent内做关系分析和表达指导；本机微信图形程序与档案工具需要完整项目和依赖。

## 方法与资料

固定版本的43份参考资料覆盖接话、情绪、邀约、冲突、互惠、依恋、人格、同意、分手和家庭。运行时按场景只读1–3份，不将整库塞给模型。参考资料与Python安装包同步校验，来源和哈希可追溯。见 [架构与改造说明](docs/coach-architecture.md)。

资料是研究、理论与经验材料，不是读心依据或实时法律、医疗数据库。MBTI和主观评分可留空，不给人定价，不输出好感概率，不承诺关系结果。

## 历史与精简档案

- 指定对象的TXT/JSON导入、去重、绑定同步、搜索及当前私聊画面读取继续可用。
- 双方身份、资料、目标与记忆按对象隔离；已有数据不因升级重写。
- 原始文字档案留在本机，单次只选择近期和相关记录；可预览实际上下文。
- 新增独立的五层精简档案：本人、对象、关系、关键事件、暂定假设；默认未启用。
- 模型只提出记忆候选，本人核对后保存；可查看、暂停、恢复、撤销、撤回同意或忘记对象。精简档案有来源和容量上限。

图片、语音和附件正文尚未解读；未导入或未同步到电脑的历史不在覆盖范围内。微信OCR与可选读取器受客户端、系统和授权影响；TXT导入和手动粘贴可独立使用，不保证所有微信版本接通。

## 模型与隐私

Codex复用本机ChatGPT登录，不读取或复制登录令牌。API密钥在本机遮蔽输入，Windows DPAPI加密。生成及整理记忆会把所选内容发送给本人选择的模型服务并使用额度；导入、检索、预览及档案控制在本机完成。

正文与内部建议经过结构、原文引用和模型复审，仍需本人核对。程序没有发送按钮；生成、复制、模拟都不算已发送，也不推进真实关系状态。仓库不包含私人配置、密钥、聊天、数据库和账号缓存。

## 开发与升级

`pytest`验证程序行为，`ruff check .`检查代码；`python scripts/sync_coach_references.py --check`校验知识副本；`pip wheel . --no-deps`构建含知识资料的安装包。真实模型质量与真实微信接入需分别验证。

旧模型配置、历史、人设、双方资料与目标沿用。原OpenDate CLI和技能目录保留兼容，微信桌面主流程使用新军师内核。源码分享包由 `scripts/package_share.py`生成，排除私有数据和本地Git历史。
